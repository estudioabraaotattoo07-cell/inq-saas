# OS PRINCÍPIOS DE UX (EXPERIÊNCIA DO USUÁRIO) DO INK SYSTEM

## Manifesto do Ink System — Documento 02 — Filosofia Oficial do Produto

**Versão 1.0**

---

**O INK SYSTEM NÃO NASCEU PARA SER MAIS UM CRM.**

Ele nasceu porque um tatuador precisava trabalhar melhor.

Antes de existir código, existia um problema.

Antes de existir interface, existia uma rotina.

Antes de existir software, existia um estúdio.

O Ink System não foi imaginado em uma sala de reunião.

Ele nasceu no atendimento. Na agenda. No atraso. Na perda de clientes. Na organização. No financeiro. Na necessidade de fazer o dia funcionar.

Por isso ele continuará evoluindo sempre da mesma maneira:

Primeiro a vida real. Depois o software. Nunca o contrário.

**O CLIENTE NÃO COMPRA UM CRM.**

Ele compra tranquilidade. Compra organização. Compra tempo. Compra controle. Compra previsibilidade. Compra confiança.

O CRM é apenas a ferramenta.

O verdadeiro produto é devolver tempo ao tatuador para que ele possa fazer aquilo que realmente importa: criar arte.

**CADA FUNCIONALIDADE PRECISA MERECER EXISTIR.**

Nenhum recurso entra porque está na moda.

Nenhum recurso entra porque outro sistema possui.

Nenhum recurso entra porque parece interessante.

Toda funcionalidade precisa responder apenas uma pergunta: Ela resolve um problema real?

Se a resposta for não, ela não pertence ao Ink System.

**O LABORATÓRIO É O MAIOR DIFERENCIAL DO PRODUTO.**

Todo sistema pode ser desenvolvido. Poucos podem ser vividos.

O Ink System vive diariamente dentro do Laboratório P&D.

Isso significa que toda melhoria nasce de uso verdadeiro.

Cada erro encontrado melhora o produto.

Cada dificuldade percebida gera evolução.

O Laboratório não existe para testar ideias. Existe para viver a realidade antes dos clientes.

**O CLIENTE NUNCA SERÁ BETA TESTER.**

Quem assume esse papel é o Laboratório.

O cliente deve receber apenas aquilo que já foi utilizado, corrigido e aprovado.

Cada Release representa um compromisso de estabilidade. Nunca uma promessa.

**MENOS É MAIS.**

Adicionar funcionalidades é fácil. Remover complexidade é difícil.

O Ink System sempre escolherá o caminho da simplicidade.

Um botão a menos vale mais do que uma tela nova.

Uma decisão automática vale mais do que três configurações.

Uma interface clara vale mais do que dezenas de opções.

**O SISTEMA DEVE PENSAR PELO USUÁRIO.**

O usuário não deve decorar processos.

O sistema deve conduzir naturalmente cada ação.

Sempre que possível: o sistema sugere. o sistema organiza. o sistema lembra. o sistema protege.

A tecnologia deve desaparecer. O trabalho do usuário deve aparecer.

**O TEMPO É O RECURSO MAIS VALIOSO.**

Todo minuto economizado representa mais atendimento. Mais criação. Mais faturamento. Mais qualidade de vida.

Se uma funcionalidade economiza tempo, ela tem valor.

Se apenas adiciona trabalho, ela deve ser revista.

**O PRODUTO EVOLUI, MAS NÃO MUDA DE IDENTIDADE.**

Versão 1.0. Versão 1.5. Versão 2.0. Versão 10.

Nada disso muda o propósito.

As versões representam evolução. Nunca mudança de essência.

**O SUCESSO DO INK SYSTEM NÃO SERÁ MEDIDO PELO NÚMERO DE FUNCIONALIDADES.**

Será medido pela quantidade de estúdios que trabalham melhor graças a ele.

Quanto menos o usuário precisar pensar para administrar seu estúdio, mais bem-sucedido será o Ink System.

**A ÚLTIMA REGRA.**

Toda decisão futura deverá responder apenas três perguntas:

Isso resolve um problema real?

Isso torna o sistema mais simples?

Isso respeita a Constituição do Ink System?

Se qualquer uma dessas respostas for "não", a decisão deverá ser reavaliada antes de seguir.

## EPÍLOGO

O Ink System não pretende ser o maior software para estúdios de tatuagem.

Pretende ser aquele em que o tatuador mais confia para organizar seu trabalho.

Porque, no fim, um software não é lembrado pela quantidade de telas que possui.

É lembrado pela tranquilidade que proporciona todos os dias.
